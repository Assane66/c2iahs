# **App Name**: SchoolZenith Admin

## Core Features:

- Secure Login: Email and password authentication using Firebase Authentication to ensure only authorized personnel access the admin panel.
- Student Roster Display: Display the school's list of students, searchable and sortable.
- Classroom Overview: Overview of classes. Display each class, teacher, and students. Provide interface to modify the data and settings of the class
- Payment Records: Digital payment records and history

## Style Guidelines:

- Primary color: Slate blue (#778DA9) for a calm, professional, and trustworthy feel.
- Background color: Very light gray (#E0E1DD). Offers a clean and neutral backdrop.
- Accent color: Pale cyan (#99D9EA) to highlight key interactive elements.
- Body and headline font: 'Inter', a sans-serif font providing a clean, modern, and very readable user interface.
- Modern, clean and responsive design with a sidebar navigation for main sections (Dashboard, Students, Classes, Payments).
- Simple, consistent icons for navigation and data visualization.
- Subtle transitions and feedback animations for a smooth user experience.
